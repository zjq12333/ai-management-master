# AI管理大师

AI管理大师是一个面向本地 Codex Desktop 的聊天记录恢复工具。

它当前主要提供这些功能：

- 搜索本机还能恢复的聊天记录；
- 恢复左侧历史和工作区分组；
- 在必要时修复“聊天明明还在，但桌面端不显示”的识别问题；
- 用图形界面完成以上操作，尽量不让用户碰底层文件。

正常情况下，你不用管自己以前是怎么登录 Codex 的，也不用管切过什么提供商。工具会先搜索所有来源的聊天记录；只有恢复后仍然看不到聊天时，再尝试“修复隐藏聊天识别”。

## 适合处理的问题

- 左侧历史记录突然不见了；
- 聊天还在本机，但桌面端不显示；
- 工作区分组乱了，聊天跑错位置；
- 旧配置或旧中转残留，导致部分聊天识别异常；
- 想先预览能恢复多少，再决定是否正式恢复。

## 安全默认行为

默认只会恢复“真实、可见、仍然有效”的聊天。

默认包含：

- 有用户消息的会话；
- 未归档的会话；
- 仍然有对应会话文件的会话；
- 工作目录仍然存在的会话；
- 工作目录不是空文件夹的会话。

默认跳过：

- 已归档会话；
- 已删除工作区对应的会话；
- 空工作区对应的会话；
- 没有用户消息的空线程；
- 找不到会话文件的线程。

正式恢复前会自动备份关键状态文件，不会直接删除聊天内容。

## 最简单用法

打开图形界面：

```text
Run-CodexMaintenanceGUI.cmd
```

如果你不想看到黑色命令行窗口，可以双击：

```text
Run-CodexMaintenanceGUI.vbs
```

推荐流程：

1. 打开工具。
2. 确认顶部显示“有效 Codex 数据目录”。
3. 点击“搜索聊天记录”。
4. 查看可恢复数量和跳过数量。
5. 关闭 Codex Desktop。
6. 点击“恢复聊天记录”。

## 高级设置说明

高级设置默认不用动，只有你明确知道自己要恢复什么时再打开。

- `包含归档`
  会把已归档聊天也列入搜索和恢复结果。

- `允许已删除工作区`
  会显示原工作目录已经不存在的聊天。

- `允许空工作区`
  会显示目录还在但已经空掉的聊天。

- `允许缺失 session`
  会显示找不到会话文件的记录，这类记录可能无法完整打开。

- `取消所选归档标记`
  正式恢复时会把选中的归档聊天改成未归档。

- `修复隐藏聊天识别`
  正常不用打开。只有恢复后聊天仍然不显示时，再尝试修正旧聊天的识别标记。

- `允许安装 threadripper`
  会通过 npm 安装辅助工具，需要联网。
